SVG Viewer for Confluence

Display attached SVGs as real vectors — working links, tooltips, percent sizing and pan & zoom. Runs entirely on Atlassian.

Quick start

  1. Attach an .svg file to a Confluence page.
  2. Type /svg in the editor and insert SVG Viewer.
  3. Publish. With no configuration the macro shows the first SVG attachment on the page.

Options

  • filename — pick a specific attachment when the page has several SVGs.
  • width — e.g. 100% or 600px (native Confluence renders percentage-sized SVGs as invisible; the macro scales them correctly).
  • zoom — true shows pan & zoom controls.
  • links — false disables hyperlinks inside the SVG.

Why not just paste the SVG as an image?

Confluence renders SVG attachments as flat images: links inside the SVG don't work, tooltips never show, percentage-sized SVGs disappear, and PDF exports drop them. The macro renders the real vector instead.
